## LitePPTX 1.7.0: Search everywhere, bookmarks, night mode, batch PDF compression

The power release: the app now remembers where you were, finds text across all your files, reads comfortably at night, and shrinks a whole folder of PDFs at once. Still zero dependencies, still tiny.

### New features

- **Global search.** From the home menu, **Search all files** looks through the text of every recent file — presentations, Word documents, spreadsheets and plain text — with a snippet for each hit. Tapping a hit opens the file right at that slide, block or row. PDFs are excluded: Android's `PdfRenderer` cannot extract text, and the app says so instead of pretending.
- **Bookmarks.** In any viewer, **⋯ → Bookmark** saves the current slide, document block, sheet row or PDF page. The home screen shows a **Bookmarks** section; tap to jump straight back, long-press (or the ×) to delete. The menu item shows a check mark when the current position is already bookmarked.
- **Night mode.** A **⋯ → Night mode** toggle in the home menu and in every viewer, remembered across sessions. Presentations and PDFs get a dim overlay over the rendered pages — the bitmaps are never inverted, so colours stay true. Documents and sheets switch to a black page with lightened text and darkened cell fills.
- **Batch PDF compression.** **PDF Tools → Compress** now accepts several PDFs at once. Each file gets the same treatment as before — lossless first, and if that saves under 5% a rendered rebuild at the current preset, with no question asked per file. A results list shows every file with its before → after size and the method used, and each result has its own **Save** button.
- **Recent files, better.** Long-press a recent file for its details — type, slide/block/row count, size and when you last opened it. The home menu can sort recents by recency, name or type, and remembers your choice.

### Fixes

- **Sharing a PDF into the app now works.** The PDF viewer had no *Share* filter and only read the file from `intent.data`; it now accepts shared PDFs. Sharing a legacy `.ppt` into the document viewer works too, and `.markdown` files open from the file manager like `.md` does.
- **Documents no longer render black text on a black background.** The office viewer used to draw DOCX default text in black on its dark page; the page is now white in day mode (and black with light text at night).

### Technical

- New `BookmarkStore` (SharedPreferences JSON, modeled on `RecentStore`) and `GlobalSearch`, which reuses the existing PPTX and office parsers on a background thread with debounced input.
- No new permissions, no new libraries, no androidx, no `java.time`.

### Limitations (honest)

- Global search covers recent files only, and never PDFs.
- Legacy `.doc`/`.ppt`/`.xls` are text-only; charts/SmartArt are still not rendered.
- Lossless PDF compression only works on classic xref-table PDFs. Most PDFs from scanners and office apps qualify; PDFs with object streams fall back to the rendered rebuild.
- The rendered rebuild turns pages into images, so text can no longer be selected or searched.
