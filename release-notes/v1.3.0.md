## LitePPTX 1.3.0: one-tap updates

LitePPTX can now keep itself up to date. When a newer release is published, an update bar appears at the top of the app. Tap **Update**, and the new build downloads and opens in Android's installer. No browser, no hunting for the APK.

### What's new

**Self-updating**
- Checks GitHub Releases at most every 6 hours, and on demand from **⋯ > Check for updates**.
- Tap the update bar to read *What's new* before you commit.
- The download is verified before the installer opens: size, SHA-256 (from GitHub) and package identity. Android itself refuses any APK that is not signed with the same key as your installed copy.
- Cancel any time while downloading.
- The first time, Android asks you to allow installs from LitePPTX; allow it once and tap **Install** again.

**Releases**
- Releases are now versioned (`v1.3.0`) and published automatically from a signed CI build, with a `.sha256` file next to the APK.

### Also in this app (from earlier versions)
- **PPTX viewer:** master/layout inheritance, shapes, tables, gradients, bullets, right-to-left text (Persian/Arabic), cropped pictures, pinch-to-zoom.
- **Images to PDF:** share photos to *Create PDF*, reorder / rotate / remove, Fit / A4 / Letter, margins, four quality presets. JPEGs are embedded untouched whenever possible; PNG screenshots stay lossless.

### Install

1. Download **LitePPTXViewer.apk** below (about 90 KB).
2. Open it and allow installation from your browser or file manager if Android asks.
3. Already have LitePPTX 1.1 or 1.2? Install this APK over it. If Android refuses because the signing key differs (builds before 1.1 used a temporary key), uninstall the old copy first. From 1.3.0 onward updates come from inside the app.

Requires Android 5.0 or newer.

### Verify the download

```
sha256sum -c LitePPTXViewer.apk.sha256
```

### Known limitations
- Charts and SmartArt are not rendered; some preset shapes (arrows, stars) are drawn as rectangles.
- Legacy `.ppt` files are not supported, only `.pptx`.
- Animations and transitions are ignored.
