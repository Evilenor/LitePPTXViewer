## LitePPTX 1.5.0: PDF viewer, speaker notes, slide search, ID cards and more shapes

The biggest feature release yet — still zero dependencies, still under 160 KB.

### New features

- **Built-in PDF viewer.** Open any PDF file from a file manager, browser, or the new *Open PDF* tile on the start screen. Pinch-to-zoom, page jump, share, save, open externally, and keep screen on — all built on Android's `PdfRenderer`, no libraries.
- **Speaker notes.** A notes badge appears on the slide counter when a slide has notes. Tap it (or use **⋯ → Speaker notes**) to read them.
- **Slide search.** **⋯ → Search slides** finds text across shapes, tables, and notes, and jumps to the matching slide.
- **Share current slide.** **⋯ → Share current slide** renders the visible slide as a PNG and opens the share sheet.
- **Go to slide.** **⋯ → Go to slide** shows a slider and number input to jump to any slide instantly.
- **Keep screen on.** A toggle in the overflow menu prevents the screen from dimming while you read.
- **ID card scanning.** A new *ID Card* mode in the scanner captures front and back, then composites both onto one A4 page at 200 DPI — perfect for forms and applications.
- **Recent files.** The start screen shows your recently opened presentations with relative timestamps ("3 min ago"), slide count, and one-tap reopen. It even remembers which slide you were on.
- **15+ preset shapes.** Right arrow, left arrow, up arrow, down arrow, five-pointed star, hexagon, pentagon, chevron, home plate, parallelogram, trapezoid, plus, and improved diamond — all rendered as proper polygons instead of rectangles.

### Improvements

- Home screen redesigned with a 2×2 tool grid (Scan, ID Card, Images to PDF, Open PDF) and the recent files list.
- Back button navigates to home instead of exiting when a deck is open.
- Scan undo button: remove the last captured page without starting over.
- PDF maker uses shared `UiHelper` and shows a selection hint.
- Shared `UiHelper.kt` for consistent insets, keep-awake, display names, and go-to dialogs across all activities.

### Technical

- APK size: ~156 KB (up from ~131 KB). Still no third-party libraries.
- `PptxModels.Slide` gains `notes` and `textContent()` for full-text search.
- `SlideRenderer` uses a `poly()` helper for clean vector shape generation.
- `ZoomableListView.isZoomed()` exposed for smarter back navigation.
- `PdfShareProvider` handles `image/png` MIME type for slide sharing.
- The updater download progress remains compatible with Android 5.0–6.0 (API 21–23).
- The display-cutout theme setting is limited to Android 8.1+ (API 27+).
